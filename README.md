# Airbnb Price Estimation

Build a service that recommends a nightly price from the features of an Airbnb listing.

## Approach

- Exploratory and geographic analysis of listings
- Statistical feature checks, including chi-square tests
- Linear Regression, Ridge, Lasso, Decision Tree, Random Forest, AdaBoost and SVR

## Results

RMSE between about 0.15 and 0.17 in the saved notebook output.
